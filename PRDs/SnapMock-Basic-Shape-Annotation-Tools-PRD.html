Document Overview

Purpose

This document defines the detailed functional requirements for the seven basic shape and drawing annotation tools in SnapMock: Line, Arrow, Rectangle, Ellipse, Arc, Polygon, and Freehand / Pen. These tools share substantial common behavior — drawing workflow, modifier keys, shared vector properties — so they are covered together in a single product requirements document. Each tool section specifies only the behavior unique to that tool.

Scope

This document covers the drawing interaction for each shape, tool-specific properties, modifier key behavior, visual feedback during creation, the resulting scene item data model, serialization format, and acceptance criteria.

Post-creation editing — selection, move, resize, rotate — is handled by the Select / Move tool defined in the Navigation and Raster Operations product requirements document.

Common Drawing Workflow

State machine

Every shape tool follows this three-state lifecycle.

StateDescriptionTransitions
Idle Tool is active, waiting for the user to begin drawing. Mouse press on canvas → Drawing.
Drawing User is actively defining the shape by dragging, or clicking for polygon.

Mouse release → Created, for drag-based tools.

Double-click or Enter → Created, for polygon.
Created The shape item has been added to the scene. Tool returns to Idle, ready for the next shape. Automatic transition back to Idle.
Mouse press (Idle → Drawing)
  1. Verify the active layer is visible and unlocked. If not, show a status bar warning ("Cannot draw on a locked/hidden layer") and ignore the press.
  2. Record the press position in canvas coordinates as origin_point.
  3. Create a temporary preview item, not yet added to the scene's item collection, to provide real-time visual feedback.
  4. Transition to the Drawing state.
Mouse move (during Drawing)
  1. Calculate the shape geometry from origin_point to the current mouse position, applying any active modifier constraints.
  2. Update the preview item's geometry in real time.
  3. Display dimensions near the cursor. These are tool-specific: length for lines, width by height for rectangles, radius for circles.
  4. If Snap to Grid is enabled, snap the endpoint to the nearest grid intersection.
Mouse release (Drawing → Created)
  1. If the resulting shape is too small — bounding box area under 4 square pixels, or line length under 2 pixels — discard the preview and return to Idle, treating it as an accidental click.
  2. Finalize the shape item with current properties from the Tool Options Bar: stroke color, width, fill, and the rest.
  3. Assign the item a new universally unique identifier (item_id) and associate it with the active layer (layer_id).
  4. Add the item to the scene and to the active layer's item list.
  5. Push an AddItemCommand to the CommandStack.
  6. Remove the preview item and replace it with the finalized item.
  7. Transition back to Idle. The tool remains active, so the user can immediately draw another shape.
  8. The newly created item is not automatically selected, because that would interfere with rapid drawing of multiple shapes. The user must switch to the Select tool (V) to select and edit it.

Modifier Key Conventions

These modifier behaviors apply during the Drawing state for all shape tools unless overridden in the tool-specific section.

ModifierBehaviorApplies to
Shift Constrain proportions. Rectangles become squares. Ellipses become circles. Lines and arrows constrain to 0°, 15°, 30°, 45°, 60°, 75°, 90° and their reflections. All tools
Alt Draw from center. The origin_point becomes the center of the shape instead of a corner or endpoint. Rectangle, Ellipse, Arc
Shift + Alt Constrain proportions and draw from center together. Rectangle, Ellipse
Ctrl Reserved for future use, such as snapping to item edges. Currently no effect during drawing. All tools
Escape Cancel the current drawing operation. Remove the preview item. Return to Idle. All tools

Visual Feedback During Drawing

  • The preview shape is drawn with the current stroke and fill properties from the Tool Options Bar, at 70% opacity to distinguish it from finalized items.
  • A dimension tooltip follows the cursor at a 15 by 15 pixel offset from the mouse position. It displays tool-specific measurements, given in each tool section.
  • If Shift is held, a small constrain icon appears near the tooltip to indicate the constraint is active.
  • If Alt is held, a small crosshair marker is drawn at the origin_point to indicate center-draw mode.
  • Guide lines — dashed, 1 pixel, 30% opacity accent color — extend from the shape edges to the rulers, when rulers are visible, to help with alignment.

Post-Creation Behavior

  • After a shape is created, the tool immediately returns to Idle and is ready for the next shape. The user does not need to re-select the tool.
  • To edit the shape's properties after creation, the user switches to the Select tool (V), selects the shape, and modifies properties in the Property Panel or Tool Options Bar.
  • To edit the shape's geometry directly, such as moving an endpoint of a line, the user selects the shape and uses TransformHandles. For shapes with control points — arc and polygon — double-clicking enters point-editing mode.
  • Rapid drawing: users can draw multiple shapes in quick succession without any intermediate steps. Each shape is a separate undo step.

Shared Tool Options Bar Controls

All shape tools show the following controls in the Tool Options Bar, in this order from left to right.

  1. Stroke Color swatch button, 24 by 24 pixels. Click for a color picker popover.
  2. Fill Color swatch button, 24 by 24 pixels. Shows a diagonal line for no fill. Click for a color picker popover.
  3. Stroke Width spin box and slider, 0.5 to 50.0, step 0.5.
  4. Stroke Style dropdown: Solid, Dashed, Dotted, DashDot, DashDotDot.
  5. Fill Opacity slider and spin box, 0% to 100%. Controls fill transparency.
  6. Stroke Opacity slider and spin box, 0% to 100%. Controls stroke transparency.
  7. Shadow toggle checkbox.
  8. Tool-specific controls, detailed in each tool section.

Changing a value in the Tool Options Bar while no item is selected updates the default for the next shape drawn. Changing a value while a shape of the matching type is selected applies the change to the selected shape, through a ModifyPropertyCommand.

Shared rendering note — flip transforms

All shape items inherit flip_horizontal and flip_vertical boolean properties from the SnapGraphicsItem base class, defined in the Technical Architecture product requirements document, Section 3.1.4. When either property is True, the item's paint() applies QPainter scale(-1, 1) or scale(1, -1) respectively around the bounding box center.

The rendering transform order is: translate to scene position, apply rotation, apply flip, then render content. These properties are toggled through the Arrange menu, the Property Panel Transform section, or the item context menu, all defined in the General UI product requirements document.

Line Tool

Overview

PropertyValue
Tool IDline
Display NameLine
Keyboard ShortcutU
Default CursorCrosshair
CategoryAnnotation
Item ClassLineItem (extends VectorItem)

The Line tool draws a straight line segment between two points.

Drawing Behavior

Geometry definition
  • The line is defined by two points: start_point, the origin_point where the mouse was pressed, and end_point, where the mouse currently is or was released.
  • The line is rendered as a QPainterPath from start_point to end_point with the configured stroke properties.
Shift constraint
  • When Shift is held during drawing, the line angle is snapped to the nearest multiple of 15 degrees: 0°, 15°, 30°, 45°, 60°, 75°, 90°, 105°, 120°, 135°, 150°, 165°, 180°, and their reflections.
  • The constrained angle is calculated from the origin_point. The endpoint is projected onto the constrained angle ray at the distance of the current mouse position from origin.
  • The most common use is Shift for perfectly horizontal, vertical, or 45-degree diagonal lines.
Alt modifier

Alt has no effect on lines, because there is no meaningful draw-from-center for a line segment. Alt is ignored.

Dimension tooltip

During drawing, display L: 245px ∠ 32.5° — length in pixels and angle in degrees from horizontal.

Minimum size

Lines shorter than 2 pixels on release are discarded, treated as an accidental click.

Tool-Specific Properties

LineItem has no additional properties beyond the shared VectorItem properties. Its geometry is fully defined by start_point and end_point.

Tool Options Bar (Additional Controls)

No additional controls beyond the shared set in Section 2.6.

Point Editing Mode

  • When a LineItem is selected with the Select tool and double-clicked, it enters point-editing mode.
  • In point-editing mode, the start_point and end_point are shown as draggable control point handles: 8 by 8 pixel filled circles in the accent color.
  • Dragging a control point moves that endpoint independently, changing the line's angle and length.
  • Shift constrains the drag to 15-degree angle increments, the same as during creation.
  • Clicking outside the item or pressing Escape exits point-editing mode.
  • Moving a control point pushes a ModifyPropertyCommand storing the old and new point positions.

Rendering

  • The line is rendered using QPainter.drawLine() or QPainterPath with the configured QPen: color, width, style, cap.
  • stroke_cap is particularly important for lines. A Flat cap ends the line exactly at the endpoints. A Round cap extends a half-circle beyond each endpoint. A Square cap extends a half-square beyond each endpoint.
  • When shadow_enabled is True, the shadow is rendered as a duplicate of the line offset by shadow_offset_x and shadow_offset_y, blurred by shadow_blur, and colored with shadow_color. The shadow is drawn first, behind the line.

shape() for Hit Testing

The shape() method returns a QPainterPath representing the line stroke area, not just the mathematical line. It is created using QPainterPathStroker with the stroke_width plus a hit-test padding of 4 pixels, so thin lines are still easy to click. This ensures users can click anywhere near the line to select it, not only exactly on the 2-pixel-wide stroke.

The Arrow tool draws a straight line with one or more arrowheads. It is the most commonly used annotation tool for pointing out interface elements, and is functionally a Line with arrowhead decorations.

Drawing Behavior

Identical to the Line tool, Section 3.2. The arrow is drawn from start_point, the tail, to end_point, the head. The arrowhead is rendered at end_point by default.

Tool-Specific Properties

PropertyTypeDefaultDescription
head_styleenumOpen Arrowhead style at the end_point. Options: None, Open (two lines), Filled (solid triangle), Diamond (filled diamond), Circle (filled circle), Square (filled square).
tail_styleenumNone Arrowhead style at the start_point. Same options as head_style.
head_sizeenumMedium Size of arrowheads. Options: Small (8px), Medium (12px), Large (18px), XLarge (24px). The actual pixel size scales with stroke_width.
head_size_customfloat0 Custom arrowhead size in pixels. Overrides the head_size enum when non-zero. Range 4 to 60.
line_styleenumStraight Line path type. Options: Straight (direct line), Curved (single bezier curve with one control point), Elbow (right-angle connector with one bend point).

Arrowhead Geometry

Open arrowhead
  • Two lines extending from the endpoint at 30 degrees on each side of the line direction.
  • Line length is determined by head_size. The lines use the same stroke_width and stroke_color as the shaft.
  • stroke_cap on the arrowhead lines is always Round for a clean look.
Filled arrowhead
  • An isosceles triangle with its tip at the endpoint, centered on the line direction.
  • The triangle base width is twice the head_size. The triangle height, from tip to base, equals head_size.
  • The triangle is filled with stroke_color, not fill_color, which controls the line's body fill.
  • The line shaft ends at the base of the triangle, not at the endpoint, so there is no overlap.
Diamond arrowhead
  • A diamond, a rotated square, centered at the endpoint.
  • Width and height equal head_size.
  • Filled with stroke_color.
Circle arrowhead
  • A circle centered at the endpoint, with diameter equal to head_size.
  • Filled with stroke_color.
Square arrowhead
  • A square centered at the endpoint, with side length equal to head_size.
  • Rotated to align with the line direction.
  • Filled with stroke_color.

Curved Arrow

  • When line_style is Curved, the line is rendered as a quadratic Bezier curve.
  • During initial drawing by drag, the curve is a straight line. After creation, the user can enter point-editing mode by double-clicking to adjust the curve.
  • In point-editing mode, a single control point is shown at the midpoint of the line. Dragging the control point adjusts the curve's curvature.
  • The control point is rendered as a 10 by 10 pixel circle in a different color, green, to distinguish it from endpoint handles.
  • Dashed guide lines connect the control point to the start and end points.
  • The arrowheads are oriented tangent to the curve at the endpoint, not along the straight-line direction between start and end.

Elbow Arrow (Right-Angle Connector)

  • When line_style is Elbow, the line consists of two or three segments meeting at right angles.
  • The bend point is automatically calculated. By default the horizontal segment extends from start_point to the midpoint X, then a vertical segment connects to the end_point Y, then a horizontal segment reaches end_point, creating an L or Z shape depending on relative positions.
  • In point-editing mode, the bend point can be dragged to adjust the position of the right-angle turn.
  • The bend point is constrained to maintain right angles in all segments.
  • Arrowheads orient along the direction of the terminal segment.

Tool Options Bar (Additional Controls)

In addition to the shared controls in Section 2.6:

  • Head Style dropdown with visual icons for each option: None, Open, Filled, Diamond, Circle, Square.
  • Tail Style dropdown, same options.
  • Head Size dropdown — Small, Medium, Large, XLarge — or a custom spin box.
  • Line Style toggle buttons with icons: Straight, Curved, Elbow.

Rectangle Tool

Overview

Item ClassRectangleItem (extends VectorItem)

The Rectangle tool draws rectangles and squares with optional rounded corners and fill.

Drawing Behavior

Geometry definition
  • The rectangle is defined by two diagonal corners: origin_point, where the mouse was pressed, and the current mouse position.
  • The rectangle is always axis-aligned during drawing, with no rotation. Rotation is applied post-creation through TransformHandles.
Shift constraint

Shift constrains the rectangle to a perfect square. The side length equals the larger of the width or height from the unconstrained rectangle.

Alt modifier

Alt draws from center: origin_point becomes the center of the rectangle, and the rectangle extends equally in all four directions to the cursor position.

Shift + Alt

Constrains to a square drawn from center.

Dimension tooltip

During drawing, display W: 320 H: 240 — width and height in pixels.

Minimum size

Rectangles with area less than 4 square pixels are discarded on release.

Tool-Specific Properties

PropertyTypeDefaultDescription
corner_radiusfloat0.0 Border radius for rounded rectangles, in pixels. Range 0 to the smaller of half the width and half the height. Zero produces sharp corners.
corner_radius_modeenumUniform Uniform: all four corners use the same radius. Individual: each corner has its own radius, set by corner_radius_tl, _tr, _bl, _br.
corner_radius_tlfloat0.0Top-left corner radius, when mode is Individual.
corner_radius_trfloat0.0Top-right corner radius.
corner_radius_blfloat0.0Bottom-left corner radius.
corner_radius_brfloat0.0Bottom-right corner radius.

Tool Options Bar (Additional Controls)

In addition to the shared controls in Section 2.6:

  • Corner Radius slider and spin box, 0 to 200 pixels, step 1. A small toggle button switches between Uniform and Individual mode.
  • When Individual mode is active, four small spin boxes appear — top-left, top-right, bottom-left, bottom-right — replacing the single slider.
  • The Fill Enabled toggle is prominently placed, since rectangles frequently use fills.

Rendering

  • When corner_radius is 0, render using QPainter.drawRect().
  • When corner_radius is greater than 0, render using QPainter.drawRoundedRect() with the specified radii.
  • When individual corner radii are set, construct a QPainterPath manually with arcTo() for each corner.
  • Fill is rendered first, if enabled, then stroke on top.
  • The fill area is inside the stroke boundary. The stroke straddles the geometric edge, with half inside and half outside.
  • When fill_enabled is True and fill_color is semi-transparent, the fill renders behind the stroke correctly without overlap artifacts.

shape() for Hit Testing

  • If fill_enabled is True, shape() returns the filled rectangle path, so clicking anywhere inside selects it.
  • If fill_enabled is False, shape() returns a QPainterPathStroker result of the rectangle outline with stroke_width plus 4 pixels of padding. Only clicking near the border selects it.
  • This distinction matters for usability: filled shapes are easy to click, unfilled shapes require clicking near the edge.

Item ClassEllipseItem (extends VectorItem)

The Ellipse tool draws ellipses and circles with optional fill. The ellipse is defined by its bounding rectangle.

Drawing Behavior

Geometry definition
  • The ellipse is inscribed within a bounding rectangle defined by two diagonal corners: origin_point and the current mouse position.
  • The ellipse center is at the center of this bounding rectangle. Its horizontal radius is half the width and its vertical radius is half the height.
Shift constraint

Shift constrains the bounding rectangle to a square, producing a perfect circle.

Alt modifier

Alt draws from center: origin_point becomes the center of the ellipse.

Shift + Alt

A perfect circle drawn from center. The origin is the center and the radius extends to the cursor distance.

Dimension tooltip

During drawing, display W: 320 H: 240, the bounding box dimensions. When Shift is held and the shape is a circle, display D: 320 for diameter or R: 160 for radius.

Minimum size

Ellipses with a bounding box area of less than 4 square pixels are discarded on release.

Tool-Specific Properties

EllipseItem has no additional properties beyond the shared VectorItem properties. Its geometry is defined by the bounding rectangle, which determines center and radii.

Tool Options Bar (Additional Controls)

No additional controls beyond the shared set in Section 2.6. The Fill Enabled toggle is prominently placed.

Rendering

  • Render using QPainter.drawEllipse() within the bounding rectangle.
  • Fill is rendered first, stroke on top, the same as the rectangle.
  • For a circle, where the radii are equal, QPainter handles this correctly and automatically.

shape() for Hit Testing

  • If fill_enabled is True, shape() returns a QPainterPath with addEllipse() for the full ellipse area.
  • If fill_enabled is False, shape() returns a QPainterPathStroker result of the ellipse outline with stroke_width plus 4 pixels of padding.

The Arc tool draws a curved arc segment, a portion of an ellipse. Arcs are useful for annotation callouts, curved connectors, brackets, and indicating rotation or motion in interface mockups.

Drawing Behavior (Three-Step Creation)

Unlike the other shape tools, which use a simple click-and-drag, the Arc tool uses a three-step creation process.

Step 1 — define the chord (click and drag)
  • Mouse press defines the arc start point. Drag to define the arc end point.
  • During drag, a straight line preview is drawn between start and end points: the chord.
  • Shift constrains the chord angle to 15-degree increments.
  • On mouse release, the chord is established. The preview shows a straight line. The tool transitions to Step 2.
Step 2 — define the curvature (move mouse, no button held)
  • After releasing the mouse, moving the cursor perpendicular to the chord adjusts the arc's curvature.
  • Moving the cursor away from the chord increases the arc's bulge. Moving back toward the chord decreases it.
  • The arc is previewed in real time as a quadratic Bezier curve or elliptical arc.
  • The curvature can go in either direction, above or below the chord.
  • Click to confirm the curvature, finalizing the arc. The tool transitions to the Created state.
  • Alternatively, pressing Enter or double-clicking confirms with the current curvature.
  • Escape cancels the entire arc and returns to Idle.
Dimension tooltip

Step 1 displays L: 245px ∠ 32.5°, the chord length and angle. Step 2 displays Arc: 315px Bulge: 45px, the arc length and the perpendicular distance from the chord midpoint to the arc peak.

Tool-Specific Properties

PropertyTypeDefaultDescription
start_pointQPointFset by drawingArc start point in scene coordinates.
end_pointQPointFset by drawingArc end point in scene coordinates.
control_pointQPointFset by drawingBezier control point defining the arc curvature.
arc_typeenumOpen Open: just the arc curve. Chord: arc plus a straight line closing the chord. Pie: arc plus two lines to the virtual ellipse center, producing a pie slice.
head_styleenumNoneOptional arrowhead at end_point. Same options as ArrowItem.
tail_styleenumNoneOptional arrowhead at start_point.
head_sizeenumMediumArrowhead size. Same options as ArrowItem.

Tool Options Bar (Additional Controls)

In addition to the shared controls:

  • Arc Type toggle buttons with icons: Open, Chord, Pie.
  • Head Style and Tail Style dropdowns, the same as the Arrow tool but defaulting to None.
  • Head Size dropdown.

Point Editing Mode

  • Double-clicking a selected ArcItem enters point-editing mode.
  • Three control point handles are shown: start_point as a blue circle, end_point as a blue circle, and control_point as a green circle.
  • Dragging start_point or end_point moves that endpoint.
  • Dragging control_point adjusts the curvature.
  • Dashed guide lines connect the control point to the start and end points.
  • Shift on endpoint drag constrains the chord angle to 15-degree increments.
  • Escape exits point-editing mode.

Rendering

  • The arc is rendered as a quadratic Bezier curve using QPainterPath.quadTo(control_point, end_point) starting from start_point.
  • If arc_type is Chord, a closing straight line is drawn from end_point back to start_point. If fill_enabled, the enclosed area is filled.
  • If arc_type is Pie, lines are drawn from start_point and end_point to the virtual center of the ellipse the arc belongs to. If fill_enabled, the pie slice area is filled.
  • Arrowheads, if configured, are oriented tangent to the curve at the respective endpoint.

The Polygon tool draws arbitrary closed polygons by clicking to place vertices. It supports both freeform polygons of any shape and regular polygons such as equilateral triangles, pentagons, hexagons, and stars.

Drawing Modes

The Polygon tool has two drawing modes, selectable in the Tool Options Bar.

Freeform polygon mode
  • Each left-click places a vertex at the cursor position.
  • A preview line is drawn from the last placed vertex to the current cursor position.
  • A closing preview line — dashed, low opacity — is drawn from the current cursor position back to the first vertex, showing what the polygon would look like if closed now.
  • Shift constrains the preview line to 15-degree angle increments from the last vertex.
  • Double-click places the final vertex and closes the polygon. Alternatively, clicking on or within 10 pixels of the first vertex closes the polygon.
  • Pressing Enter closes the polygon using the last-placed vertex, without adding a new one at the current cursor position.
  • Right-click removes the last-placed vertex. Repeated right-clicks undo multiple vertices.
  • Escape cancels the entire polygon, removing all vertices and returning to Idle.
  • A minimum of 3 vertices is required. If the user tries to close with fewer than 3 vertices, the polygon is canceled.
Regular polygon mode
  • The user clicks to define the center and drags to define the radius and initial rotation.
  • The number of sides is set in the Tool Options Bar, 3 to 64, default 5.
  • During drag, the regular polygon is previewed with the configured number of sides, centered on the click position, with one vertex pointing toward the cursor.
  • Shift constrains the rotation to 15-degree increments.
  • Release finalizes the polygon.
  • The Star option indents alternate vertices to create star shapes.

Point Editing Mode

Freeform polygon
  • Double-clicking a selected PolygonItem enters point-editing mode.
  • All vertices are shown as draggable control point handles: 8 by 8 pixel filled circles.
  • Dragging a vertex moves it. Shift constrains to a 15-degree angle from the previous vertex.
  • Double-clicking on a segment between two vertices inserts a new vertex at that point.
  • Right-clicking on a vertex deletes it, if more than 3 vertices remain.
  • Escape exits point-editing mode.
Regular polygon
  • Point-editing mode shows the center point and one radius and rotation handle.
  • Dragging the center moves the entire polygon.
  • Dragging the radius handle changes the size and rotation.
  • Individual vertex editing is not available for regular polygons, because the shape is defined by sides, center, radius, and rotation.

Rendering

  • Freeform: construct a QPainterPath using moveTo() for the first vertex and lineTo() for each subsequent vertex. If closed, call closeSubpath().
  • Regular: compute vertex positions using trigonometry, where the angle is 2π times the index divided by the number of sides, starting from the rotation angle. For stars, alternate between the outer radius and the inner radius, which is the outer radius times star_indent.
  • Fill, stroke, and shadow rendering follow the same rules as Rectangle and Ellipse.

shape() for Hit Testing

Same logic as Rectangle. If fill_enabled, the shape is the filled polygon path. If not filled, the shape is a stroked version of the outline path with padding.

The Freehand / Pen tool draws smooth, free-form strokes by tracking the mouse path. It is used for hand-drawn annotations, circling areas of interest, underlining text in screenshots, sketching rough outlines, and any annotation that benefits from a natural, hand-drawn appearance.

Drawing Behavior

Mouse press
  • Verify the active layer is visible and unlocked. If not, show a status bar warning and ignore.
  • Record the press position as the first point in the path.
  • Begin capturing mouse move events to build the stroke path.
  • Change the cursor to a small filled circle — diameter equal to stroke_width, colored with stroke_color — to provide a brush tip visual.
Mouse move (drawing)
  • Append the current mouse position to the raw path point list.
  • Points are sampled at the mouse event rate, typically 60 to 120 Hz depending on the platform and input device.
  • Render the stroke in real time from the first point through all recorded points using the current stroke properties.
  • The stroke is rendered as a QPainterPath using quadratic Bezier curves between consecutive points, not straight line segments, for inherent smoothness even before post-processing.
  • If pressure-sensitive input is detected from a tablet or stylus, record pressure values alongside each point for future pressure-width mapping. Version 1.0 uses uniform width; pressure support is a future enhancement.
Mouse release
  • Stop capturing points. The raw path is complete.
  • Apply path simplification, described in Section 9.3, based on the smoothing setting.
  • If the resulting path has fewer than 2 points, or a bounding box area under 4 square pixels, discard the stroke as an accidental click.
  • Finalize the FreehandItem with the simplified path and current stroke properties.
  • Add to the scene and active layer. Push an AddItemCommand.
  • Return to Idle. The tool remains active for the next stroke.

Path Smoothing and Simplification

Raw mouse input produces jagged, noisy paths. SnapMock applies a two-stage smoothing pipeline controlled by the Smoothing slider, 0% to 100%.

Stage 1 — Ramer-Douglas-Peucker simplification
  • Reduces the number of points by eliminating points within a tolerance distance of the simplified line.
  • Tolerance is calculated from the smoothing value: tolerance equals smoothing times 0.01 times 5.0 pixels. At 0% smoothing the tolerance is 0 pixels and no points are removed; at 100% the tolerance is 5 pixels.
  • This removes redundant points on straight-ish segments while preserving sharp direction changes.
  • Typical reduction: a raw stroke of 500 points may reduce to 50 to 100 points at moderate smoothing.
Stage 2 — cubic Bezier curve fitting
  • The simplified point set is converted to a series of cubic Bezier curves using a least-squares curve fitting algorithm.
  • The maximum fitting error is controlled by smoothing: the error threshold equals smoothing times 0.01 times 3.0 pixels.
  • At 0% smoothing, the Bezier curves closely follow the original points, giving a nearly raw path.
  • At 100% smoothing, the Bezier curves produce very smooth, flowing lines that may deviate noticeably from the raw input.
  • The result is stored as a list of cubic Bezier segments, each defined by four control points: start, cp1, cp2, end.
Real-time versus post-processing
  • During drawing, while the mouse is held, the stroke is rendered using the raw points connected by quadratic Bezier interpolation. This provides a smooth real-time preview without the computational cost of full curve fitting.
  • On mouse release, the full two-stage smoothing pipeline runs and replaces the raw path with the optimized Bezier path.
  • There may be a subtle visual snap as the raw path is replaced by the smoothed path. At moderate smoothing levels, 30% to 60%, this is barely perceptible. At high smoothing, 80% to 100%, the path may visibly simplify on release. This is expected behavior.

Modifier Keys

  • Shift, held during drawing, constrains the stroke to straight line segments. As the user drags, the stroke follows horizontal, vertical, or 45-degree diagonal lines from the last direction change point. This allows mixing freehand curves with precise straight segments in a single stroke.
  • Alt has no effect during freehand drawing.
  • Escape cancels the current stroke in progress, removes the preview, and returns to Idle.

Tool Options Bar

In addition to the shared shape controls in Section 2.6:

  • Smoothing slider, 0% to 100%, default 50%. A label shows the current value. The slider has visual tick marks at 0%, 25%, 50%, 75%, and 100%.
  • Stroke Cap visual toggle group — Flat, Round, Square — with small icons showing the cap style.
  • Close Path toggle button. When enabled, the stroke auto-closes on release, so the last point connects to the first point. Useful for freehand-drawn enclosed regions that should be fillable.

Post-Creation Editing

Select tool
  • Click to select. TransformHandles appear around the bounding box.
  • Resize scales the entire path uniformly, with all points scaled relative to the bounding box center.
  • Rotate rotates all points around the bounding box center.
  • Move translates all points by the drag delta.
Point editing mode (double-click)
  • Double-clicking a selected FreehandItem enters point-editing mode.
  • The Bezier control points are displayed: on-curve points, the segment endpoints, as blue 6 by 6 pixel filled circles, and off-curve control points, the cp1 and cp2 handles, as green 5 by 5 pixel hollow circles connected to their on-curve point by dashed lines.
  • Dragging an on-curve point moves that point. Adjacent Bezier segments adjust to maintain continuity, giving a smooth transition. Holding Alt while dragging breaks the continuity, creating a corner or cusp.
  • Dragging a control handle adjusts the curvature of that segment.
  • Double-clicking on a path segment between two on-curve points inserts a new on-curve point, splitting the Bezier segment into two.
  • Right-clicking an on-curve point deletes it, with a minimum of 2 points remaining. Adjacent segments are merged.
  • Escape exits point-editing mode.
Re-smoothing
  • When a FreehandItem is selected and the Smoothing slider in the Tool Options Bar is changed, the path is re-smoothed from the original raw path_points using the new smoothing value.
  • This pushes a ModifyPropertyCommand storing both the old and new bezier_segments.
  • Re-smoothing is non-destructive: the original path_points are always preserved, allowing the user to increase or decrease smoothing after the fact.

Rendering

  1. Construct a QPainterPath from the bezier_segments using moveTo() for the first point and cubicTo() for each segment.
  2. If is_closed is True, call closeSubpath() to connect the last point to the first.
  3. If shadow_enabled, render the shadow: an offset, blurred duplicate of the path in shadow_color.
  4. If fill_enabled and is_closed, fill the closed path with fill_color.
  5. Stroke the path with the configured QPen: stroke_color, stroke_width, stroke_style, stroke_cap, stroke_join.
  6. During drawing, before release, render from the raw point list using QPainterPath with quadTo() for smooth interpolation between consecutive point triplets.

shape() for Hit Testing

  • If is_closed and fill_enabled, shape() returns the filled closed path, so a click anywhere inside selects it.
  • Otherwise, shape() returns a QPainterPathStroker result of the stroke path with stroke_width plus 4 pixels of padding.
  • For thin strokes, under 4 pixels, the minimum hit area width is 8 pixels to ensure clickability.

Performance Considerations

  • Raw point capture must not drop events. Use a high-priority event handler to ensure all mouse move events are recorded.
  • Real-time rendering during drawing must maintain 60 frames per second. For very long strokes, over 2000 raw points, render only the most recent 500 points during drawing and render the full path on release.
  • Path simplification and Bezier fitting on release should complete within 50 milliseconds for strokes up to 5000 raw points.
  • Bezier path rendering is efficient: QPainter handles cubic Bezier paths natively with hardware acceleration.
  • Storing both path_points, raw, and bezier_segments, smoothed, doubles the data per item. For memory optimization in projects with many freehand items, the raw path_points could be discarded after the user confirms they are satisfied with the smoothing. This is a future enhancement.

Command Definitions

All shape tools produce an AddItemCommand when a shape is created, defined in the Technical Architecture product requirements document. This section covers commands specific to shape editing.

AddItemCommand (Shape Creation)

  • Triggered on mouse release after drawing any shape, or on polygon close.
  • Stored data: complete serialized item state, layer_id.
  • redo(): add the item to the scene and layer.
  • undo(): remove the item from the scene and layer.
  • description(): "Add [Shape Type]", for example "Add Rectangle" or "Add Arrow".

ModifyPropertyCommand (Property Edit)

  • Triggered when any property is changed through the Property Panel, Tool Options Bar, or point-editing mode.
  • Stored data: item_id, property_name, old_value, new_value.
  • redo(): set item.property_name to new_value.
  • undo(): set item.property_name to old_value.
  • merge_with(other): if the other command has the same item_id and property_name, and was created within 500 milliseconds, merge by replacing new_value with the other's new_value. This coalesces rapid slider adjustments into a single undo step.
  • description(): "Change [Property Name] of [Shape Type]", for example "Change Stroke Color of Arrow".

ModifyGeometryCommand (Point Edit)

  • Triggered when a control point is dragged in point-editing mode.
  • Stored data: item_id, property_name — for example start_point, control_point, vertices — old_value, new_value.
  • redo(): set the geometry property to new_value.
  • undo(): set the geometry property to old_value.
  • merge_with(other): merge consecutive point drags on the same item and point within 300 milliseconds.
  • description(): "Edit [Shape Type] geometry", for example "Edit Arc geometry".

InsertVertexCommand (Polygon)

  • Triggered by double-clicking on a polygon segment in point-editing mode.
  • Stored data: item_id, vertex_index, the position in the vertices list, and vertex_position.
  • redo(): insert vertex_position into the vertices list at vertex_index.
  • undo(): remove the vertex at vertex_index.
  • description(): "Insert polygon vertex".

RemoveVertexCommand (Polygon)

  • Triggered by right-clicking a vertex in point-editing mode. A minimum of 3 vertices must remain.
  • Stored data: item_id, vertex_index, vertex_position.
  • redo(): remove the vertex at vertex_index.
  • undo(): insert vertex_position at vertex_index.
  • description(): "Remove polygon vertex".

Deserialization

  • On project load, the type field is used to select the correct item class for instantiation.
  • Each item class implements a from_dict(data) class method that constructs the item from the JSON dictionary.
  • Unknown properties in the JSON are silently ignored, for forward compatibility.
  • Missing properties use their default values, for backward compatibility.
  • Invalid values, such as a stroke_width below 0, are clamped to valid ranges with a warning logged.

Acceptance Criteria

Line Tool

  1. Click-and-drag draws a line between two points with the configured stroke properties.
  2. Shift constrains the angle to 15-degree increments. Perfectly horizontal, vertical, and 45-degree lines are easily achievable.
  3. Lines shorter than 2 pixels are discarded on release.
  4. The dimension tooltip shows length and angle during drawing.
  5. Point-editing mode, entered by double-click, allows dragging endpoints independently.
  6. All stroke properties — color, width, style, cap — render correctly.
  7. Shadow renders correctly when enabled.
  8. Hit testing selects the line when clicking within stroke_width plus 4 pixels of the line.
  9. The item serializes to and deserializes from JSON with full fidelity.

Arrow Tool

  1. Click-and-drag draws an arrow from tail to head with the configured arrowhead style.
  2. All six arrowhead styles — None, Open, Filled, Diamond, Circle, Square — render correctly.
  3. Arrowheads on both head and tail are independently configurable.
  4. Arrowhead size scales proportionally with the head_size setting.
  5. Curved arrow mode: after creation, the control point is editable in point-editing mode. Arrowheads orient tangent to the curve.
  6. Elbow arrow mode: the bend point auto-calculates and is editable in point-editing mode. Right angles are maintained.
  7. Shift constrains chord angle to 15-degree increments.
  8. All stroke properties and shadow render correctly.

Rectangle Tool

  1. Click-and-drag draws a rectangle with the configured stroke and fill.
  2. Shift constrains to a perfect square.
  3. Alt draws from center.
  4. Corner radius produces smoothly rounded corners. Values above 0 produce visible rounding.
  5. Individual corner radii produce a different radius on each corner.
  6. Fill renders correctly behind stroke with no overlap artifacts.
  7. Empty rectangles, with no fill, can only be selected by clicking near the border.
  8. Filled rectangles can be selected by clicking anywhere inside.

Ellipse Tool

  1. Click-and-drag draws an ellipse inscribed in the drag rectangle.
  2. Shift constrains to a perfect circle.
  3. Alt draws from center, where the origin is the center and the radius extends to the cursor.
  4. Fill and stroke render correctly.
  5. Hit testing respects fill_enabled for the clickable area.
  6. The dimension tooltip shows width by height, or diameter for circles.

Arc Tool

  1. The three-step creation process works correctly: drag for chord, move for curvature, click to confirm.
  2. Arc preview updates in real time during curvature adjustment.
  3. All three arc types — Open, Chord, Pie — render correctly.
  4. Optional arrowheads orient tangent to the curve at endpoints.
  5. Point-editing mode allows adjusting start, end, and control points.
  6. Shift constrains the chord angle during Step 1.
  7. Escape cancels at any step.

Polygon Tool

  1. Freeform mode: click to place vertices, double-click to close. A minimum of 3 vertices is enforced.
  2. The closing preview line shows the polygon shape before closing.
  3. Right-click removes the last vertex during drawing.
  4. Regular polygon mode: click-and-drag defines center and radius. The configured number of sides renders correctly for values 3 through 64.
  5. Star mode produces correct star shapes with a configurable indent ratio.
  6. Point-editing mode allows vertex manipulation for freeform polygons: drag to move, double-click a segment to insert, right-click to delete, with a minimum of 3 remaining.
  7. Fill and stroke render correctly for all polygon configurations.
  8. Open polylines, where closed is False, render as an open path.

Freehand / Pen Tool

  1. Click-and-drag draws a freehand stroke that follows the mouse path with real-time visual feedback.
  2. Path smoothing produces visibly smoother strokes at higher smoothing values. At 0% the stroke closely matches the raw mouse path. At 100% the stroke is noticeably smoothed.
  3. The Smoothing slider in the Tool Options Bar adjusts the smoothing level. Changing the slider on a selected FreehandItem re-smooths non-destructively from the original raw points.
  4. Shift during drawing constrains to straight horizontal, vertical, or 45-degree segments.
  5. Strokes shorter than 2 pixels, from accidental clicks, are discarded.
  6. The Close Path toggle correctly closes the path on release and enables fill.
  7. Point-editing mode, entered by double-click, displays on-curve and off-curve Bezier control points. Dragging adjusts the path. Alt+drag creates corners. Double-clicking a segment inserts a point. Right-click deletes a point, with a minimum of 2 remaining.
  8. Stroke properties — color, width, style, cap, join — render correctly on freehand paths.
  9. Shadow renders correctly when enabled.
  10. Performance: real-time drawing maintains 60 frames per second for strokes up to 5000 raw points. Path smoothing completes within 50 milliseconds on release.

Shared Behavior

  1. All shape tools respect the active layer: they cannot draw on locked or hidden layers. A status bar warning is shown.
  2. The Tool Options Bar updates dynamically when switching between shape tools.
  3. Changing Tool Options Bar values while a shape is selected applies the change to the selected shape.
  4. All shape creation operations produce an AddItemCommand and are fully undoable.
  5. Property changes produce a ModifyPropertyCommand and are undoable. Rapid changes merge within 500 milliseconds.
  6. Point-editing geometry changes produce a ModifyGeometryCommand and are undoable.
  7. All shapes serialize and deserialize correctly with full property fidelity.
  8. All shapes render correctly at zoom levels from 10% to 3200%.
  9. Snap to grid works during shape drawing when enabled.
  10. Shape creation at 4K resolution with 100 existing items maintains 60 frames per second preview rendering.
